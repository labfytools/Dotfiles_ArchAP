# Référence historique V1

Le runtime V1 a été retiré après la recette réelle réussie de Session Restore V2.
Ce document ne décrit plus de commandes exécutables. Utiliser exclusivement
[Session Restore V2](session-restore-v2.md).

Les anciennes sessions et snapshots utilisateur sous XDG_STATE_HOME sont
conservés. Aucune migration ni suppression de données n’a été effectuée.
Les sources et documents V1 antérieurs au nettoyage sont archivés dans la
branche locale de recherche `refactor/session-restore-v2`, sans publication.
L’historique Git public conserve les versions V1 précédemment publiées.
